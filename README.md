Thought Process
This project was built with a focus on creating a visually engaging and interactive user interface using animations. The layout is modular, with components like LeftDiv and RightDiv handling specific parts of the design. The goal was to ensure that the animations enhance the user experience while maintaining a clean and modern design.

Animation Library Used
The project uses Framer Motion, a declarative animation library for React, to handle animations. Framer Motion was chosen for its simplicity, flexibility, and ability to create smooth and visually appealing animations with minimal effort.
